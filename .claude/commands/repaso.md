Tema: $ARGUMENTS

1. Buscá la sección correspondiente en `docs/REPASO.md`.
2. Explicala con tus palabras en no más de 10 líneas, usando un ejemplo con el código **actual** del repo (no el del REPASO, si ya existe código real).
3. Hacé 3 preguntas de dificultad creciente, de a una, esperando cada respuesta y dando feedback.
4. Si alguna respuesta fue floja, agregala a "Preguntas para repasar" en `docs/PROGRESO.md`.

No modifiques código en este comando.
